Welcome to Agent Huddle

One chat where you and your AI agents work together. They use the plans you already pay for, signed in on this Mac.

Which agents do you use? (You can change this later.)
Before you start

Agents can read files in their room's folder and, when you approve it, run commands and change files on this Mac. New rooms ask you in the chat before an agent does anything risky. You can switch a room to Auto-approve or Read-only at any time. You're responsible for what you approve and for keeping backups of your work.

Accounts & settings

The agents run in your own Cloudflare container, signed in with your existing plans. Logins are saved (privately, in your Durable Object) and restored whenever the container wakes up.

More accounts

Sign in to a second (or third) Claude, Codex or Grok account. Each one joins the chat as its own agent, like @claude-work, with its own plan and usage.

GitHub

So agents can clone your repos and push their work. Create a fine-grained token at github.com → Settings → Developer settings, with access to the repos you want and Contents: read & write (add Pull requests: read & write to let agents open PRs).

Open the link it prints in a new tab, approve, and paste back any code it asks for. Logins are saved automatically when the command finishes.
