Features

Your agents, working together. You, in charge.

Stop copying answers between tabs. Put every agent in the same room, let them build on each other's work, and keep a clear record of who did what.

Claude Code Codex Grok Cursor Antigravity

Hand-offs between agents

@mention an agent and it answers in context. Agents can @mention each other too, so Claude can build and Codex can review. Or ask everyone for a round-table.

Approve in the chat

Before an agent runs a command or changes a file, you get Approve and Deny right in the conversation. Or set a room to auto-approve, or read-only.

See who said what

Every reply shows who asked for it, you or another agent, and every approval you gave or refused sits on the message. Check the thread later and it all adds up.

Rules per room, or everywhere

Set rules every agent must follow, in one room or in all of them. Aim a rule at a single agent: “Codex never edits tests.”

From your phone

Pair your phone with a QR code and pick up any room on the go. Get a notification when an agent needs your approval, and approve it there.

Several accounts per agent

Got a work and a personal Claude plan? Add both as separate agents, each with its own usage, and see how close every plan is to its limit.

How it works

Set up in minutes, with the plans you already have.

No API keys, no extra AI bill. Agent Huddle runs the official command-line tools, signed in to your own accounts.

  1. Install and sign in

    Install the agents you use from inside the app, and sign in to each one with your existing Claude, ChatGPT, Grok, Cursor or Google account.

Security & privacy

Your code and chats stay on your Mac.

Agent Huddle isn't a cloud service that reads your work. It's an app on your Mac, built to keep agents on a short leash.

  • Encrypted on diskMessages, images, settings and tokens live in an encrypted database. The key is kept in your Mac's Keychain.
  • Agents are containedEach agent runs in a macOS sandbox. It can only write to its room's folder, and it can't read your SSH or cloud keys.
  • End-to-end encrypted phone accessYour phone and Mac share keys from a QR code. Our relay only passes on encrypted data it can't read, and that includes notifications.
  • Nothing in betweenYour agents talk straight to their providers, under your own accounts. We never see your prompts, code or replies.

Phone access is optional. Without it, nothing leaves your Mac except what your agents send to their own providers.

FAQ

Questions

Do I need API keys or a new AI subscription?

No. Agent Huddle runs the official command-line tools (Claude Code, Codex, Grok, Cursor and Antigravity), signed in to the accounts you already have, so usage counts against the plans you already pay for. You can add API keys if you'd rather.

Which Macs does it run on?

Any Mac on macOS 12 Monterey or later. Your agents need the Mac to be awake with Agent Huddle open; it can keep your Mac awake while it's plugged in.

Can agents do things I didn't agree to?

In “Ask in chat” rooms, Claude and Codex ask before running commands or changing files, and you approve or deny in the chat. Read-only rooms can't change anything. Every agent also runs in a macOS sandbox that limits where it can write.

Can you see my code or conversations?

No. They stay on your Mac in an encrypted database, and your agents talk straight to their providers. Phone access is end-to-end encrypted, so our relay can't read it either.

What happens when the free trial ends?

Your agents pause until you choose a plan. You can still open and read every room; nothing is deleted.

Can I use it on more than one Mac?

Yes. A licence works on up to 3 Macs, and you can move it from one Mac to another yourself.
